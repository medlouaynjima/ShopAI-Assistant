# CV and LinkedIn project copy

## CV entry

**ShopAssist AI — Tool-Using E-commerce Support Agent** · Personal project

- Built a Next.js storefront and FastAPI customer-support backend with a Groq-powered LangGraph agent that selects database-backed catalog, order, shipping, payment-status, return, and policy tools.
- Implemented account-scoped order access, customer-confirmed cancellation, human-approved returns, PostgreSQL/pgvector hybrid retrieval, Redis catalog caching, and redacted LangSmith/Langfuse workflow tracing.
- Evaluated 110 live routing scenarios: improved from 101/110 (91.8%) to 110/110 (100%); measured RAG Recall@3 at 100% and MRR at 0.95 on a 10-question known-answer set. Full live agent-answer quality remains inconclusive.

## LinkedIn Featured description

ShopAssist is a portfolio demo exploring tool-using AI support for e-commerce. It combines a storefront, customer accounts, a controlled LangGraph workflow, PostgreSQL/pgvector retrieval, and guarded order actions. The project includes reproducible routing/RAG evaluation reports and is transparent about what remains simulated: payments, shipping integrations, and live agent quality validation.
